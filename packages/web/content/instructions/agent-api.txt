# Use a shared Morty Computer

A user shared a Computer with you using a continue link. The Computer runs the Agent
and retains its conversation history. Only perform the work the user requested, in a
directory they named or the session named by the link. If the Computer is offline or
the Agent is unavailable, tell the user; do not change its setup.

The link, its fragment, and the access it grants are secrets. Never print, log, commit,
or forward them. The fragment stays on your machine and is never sent to Morty.

## Run a turn

Use Node.js 24. Save the following complete fenced script as a private local file named
`morty-remote-agent.mjs`. It contains the same encrypted protocol implementation used
by Morty; it requires no package installation.

```js morty-remote-agent
{{REMOTE_AGENT_CLIENT}}
```

Import `runSharedComputer` from that file and call it from your own Node program:

```js
import { runSharedComputer } from './morty-remote-agent.mjs';

const result = await runSharedComputer({
  link,             // the user's complete continue link, kept private
  redemptionKey,    // 32 random bytes encoded base64url, persisted before redemption
  conversationKey,  // stable identifier for this intended new conversation
  turnId,           // stable identifier for this intended turn
  prompt,           // the user's requested work
  harness,          // requested Agent, e.g. 'codex'
  directory,        // a directory the user named
  signal: AbortSignal.timeout(120_000),
});
// Report result.answer to the user, not the link or credentials.
```

Generate and privately persist the redemption key, conversation key, and turn ID before
the first call. If a response is lost, retry the same link and keys with the same prompt;
never invent a new turn ID for an ambiguous submission. The helper redeems the link,
creates a conversation or opens the native session named by the link, submits the turn,
and reads its completed answer. It closes its connections when finished. Errors may
carry a machine-readable `code`; branch on that, not the message. If redemption reports
`TRANSFER_UNAVAILABLE`, ask the user for a new link.

The helper redeems access at `/morty/api/v1/identity/transfers/redeem`; it keeps the
Computer encryption secret local rather than sending the complete fragment.

Morty origin: {{BASE_URL}}

The machine-readable operation contracts are available at
{{BASE_URL}}/doc/agent-api/openapi.json and {{BASE_URL}}/doc/agent-api/asyncapi.json.
The helper above owns encryption and transport; do not send plaintext Agent payloads
or the encryption fragment directly to the Worker.
